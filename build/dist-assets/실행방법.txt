saehakgi (새학기) — 실행 방법
====================================

■ 이 프로그램은?
  기존 PC의 설정(폴더, 즐겨찾기, 공동인증서, 프로그램 목록, 시작프로그램,
  Wi-Fi, 전원, 폰트, 환경변수, 브라우저 쿠키 등)을 USB로 새 PC에 옮기고,
  옮긴 것만 다시 원래대로 되돌리는 도구입니다. 설치가 필요 없습니다.

■ 실행 방법
  1) 이 폴더의  saehakgi.exe  를 더블클릭합니다.
  2) "사용자 계정 컨트롤(UAC)" 창이 뜨면 [예]를 눌러 관리자 권한으로 실행합니다.
     (Windows 설정/Wi-Fi/전원 등을 바꾸려면 관리자 권한이 필요합니다.)
  3) 처음 실행 시 "Windows의 PC 보호(SmartScreen)" 경고가 나올 수 있습니다.
     [추가 정보] → [실행]을 누르세요.
     (서명되지 않은 프로그램이라 나타나는 정상 안내입니다.)

■ 사용 순서
  · 기존 PC : ① 내보내기 탭에서 옮길 항목 체크 → 암호 입력 → USB에 저장
  · 새   PC : ② 가져오기 탭에서 파일 선택 → 암호 입력 → 미리보기 후 적용
  · 되돌리기: ③ 초기화 탭 (이 프로그램이 옮긴 것만 원래대로)
  · 브라우저 쿠키: ④ 브라우저 쿠키 탭의 [도움말 열기]를 참고하세요.

■ 주의
  · 비밀번호는 브라우저 제한으로 옮길 수 없습니다.
    → 크롬/엣지 설정의 "비밀번호 내보내기/가져오기(CSV)"를 사용하세요.
  · 일부 사이트(구글 등)는 쿠키를 옮겨도 새 PC에서 재로그인이 필요할 수 있습니다.
  · saehakgi.exe 와 Saehakgi.Host.exe 는 반드시 같은 폴더에 두세요.
  · USB 번들과 쿠키 파일은 입력한 암호로 암호화됩니다. 암호를 잊으면 복구할 수 없습니다.
